# Zonovia Web (`web/`)

**Out of scope for Phase 0.** Per the [architecture blueprint](../docs/architecture/Zonovia-Architecture-Blueprint.md) §30, the React 19 + TypeScript + Vite + TanStack Query + Tailwind 4 web application is not built until the phase where Asset Core (Phase 1) and baseline tracking (Phase 2) have a UI worth shipping. This directory is a placeholder so the repo layout matches the blueprint's monorepo structure (§26) from day one.

When work starts here, it should follow the same stack and conventions already validated in Virasaka's sibling products (SchoolAssist, CMS).
